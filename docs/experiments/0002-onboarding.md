- 日期：2026-10-07（Asia/Shanghai）
- 状态：completed
- 用户目标：安装 MCP 后，安装 Agent 在当前上下文主动询问知识库位置，完成范围预览、配置、索引与验证。
- 主要变化：新增接入状态、目录预览和确认接入工具；服务指令和安装文档明确引导顺序。
- 验证目标：演示库不误判为已配置；预览不读取正文或改配置；变更后预览失效；接入失败保留旧配置；接入成功后同一服务进程和重启后均能检索。

## 判断与限制

采用本次接入能力。默认示例配置、源文件和历史基线保留；新增配置发布前须索引与验证成功。
同进程串行接入已有保护，但多进程同时写配置尚不支持；旧数据库快照当前保留，不自动清理。
安装命令返回提问、服务握手携带引导指令，Agent必须按顺序执行；不宣称 MCP 自主启动了模型对话。
工程测试验证指令与工具链，跨宿主安装Agent是否遵循仍需真实使用反馈。
