# EXP-0005：向量检索基线实验计划

- 状态：planned
- 实验问题：相对BM25，固定模型的dense检索对换说法/中英表达是否改善；准确词、无答案、耗时和上下文量有何代价？
- 自变量：检索路线BM25→dense；首轮模型与输入模板固定，不同时改变父chunk或加入重排。
- 推荐配置：Qdrant本地服务 + 本地multilingual-e5-small，模型revision与依赖版本在执行时锁定。
- 数据：smoke-v1用于公共回归；真实开发/保留测试集放 `.local/`，未建立前不声称真实知识库效果提升。
- 固定条件：相同语料快照、父chunk、范围/状态过滤、top_k、正文预算、预热/测量次数与输出契约。
- 测量：Recall/MRR/nDCG、类别与逐题变化、无答案候选、query_embed/vector_query/source_resolve阶段、p50/p95、正文和响应字节。
- 构建指标：首次编码token/时间、点数/覆盖、存储体积、缓存命中率、增量重算量、删除同步与失败恢复。

## 实验顺序

1. 固定测试向量验证存储契约，不计算真实语义质量。
2. 公开演示语料建立模型与存储基线，记录模型下载/冷启动与暖查询。
3. 建立私有真实标签集，冻结保留测试集；调参只用开发集。
4. 同条件跑BM25与dense，保存两侧完整本地报告，比较失败与退化。
5. 另起实验比较hybrid；近似索引、模型替换、切块变化均单独实验。

## 采用判断

所有索引一致性、过滤、引用和隐私约束通过。检索策略是否默认启用由真实数据收益与代价决定。
如果dense只改善某些类别，保留可选策略或进入hybrid实验，不强行替换BM25。
没有数据之前不报告提升百分比或性能收益。

实现细节见 [向量索引计划](../vector-index-plan.md)。
