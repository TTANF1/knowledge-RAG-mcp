# EXP-0004：本地实验与公开发布边界

- 状态：completed
- 目标：保留本地完整数据用于改善检索，同时控制公开代码、文档和实验摘要的发布范围。
- 变化：扩大忽略规则；将本机与个人记录转入 `.local/`；原始评测档案停止跟踪；公开指标由验证后的合成报告导出。
- 检索算法、知识库内容和活动数据库未改动；本次不声明检索质量或性能收益。

## 验证

33项测试通过，其中8项为新增隐私边界测试：

- 私有目录、数据库变体、日志和未经批准的JSONL被拦截。
- `git add -f` 强制暂存私有文件仍被提交检查发现。
- 暂存内容含隐私时，工作区后续修正不能使检查误通过。
- 当前文件清理后，旧提交中的本机信息仍能被历史检查发现。
- 公开源代码副本不包含 Git 历史、活动数据或私有学习笔记。
- 合成摘要不含原始逐题记录和本机环境详情；语料不符时拒绝导出。

工作区发布候选检查通过。提交和推送钩子分别调用暂存检查与历史检查。
所有历史源档案在本地保留；公开摘要可参见 `benchmarks/public/`，重新运行演示评测可获得新的完整本地报告。

## 边界

规则检查覆盖文件类型、目录、已知路径、明显密钥模式与报告结构，不能代替公开笔记的语义审阅。
本地钩子可被显式绕过，克隆后的使用者需要自行启用。历史清理不会自动执行；首次发布可使用无历史副本。
