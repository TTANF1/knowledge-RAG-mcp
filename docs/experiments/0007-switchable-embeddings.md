# EXP-0007：可切换编码与真实向量检索

- 日期：2026-10-10；状态：completed（本地编码/构建/dense与API模拟协议）；Server与供应商实测待完成。
- 假设：固定 E5-small 的 CPU 编码可运行；完整窗口不会丢失长片段末尾；缓存使无变化输入的编码调用为0。
- 自变量：新增真实编码及 dense；BM25算法、公开语料、父片段、top_k=5、4000字符预算保持不变。
- 路径：本地 ONNX CPU 与兼容 embeddings API 可配置切换；不同 provider/model/revision/模板/服务身份隔离缓存与代次。
- 主要验收：维度/归一化、超限显式拒绝、长文本覆盖、缓存命中、失败保留已发布代次、版本与范围过滤。
- 指标：冷加载/编码/查询耗时、token/单元数、缓存 hits/misses、构建点数、进程内存、Recall/MRR/nDCG、无答案候选及响应大小。
- 数据：公开 smoke-v1 合成开发集；私有索引只在本地构建，原始报告/模型/缓存/配置均不提交。
- API 无真实凭证时用模拟 HTTP 服务验证协议、顺序、错误与密钥脱敏，不能声称真实服务验收。
- 限制：小型开发集与单轮 CPU 时延不能证明泛化或生产性能；不预设语义效果优于BM25。

## 结果

固定模型 `intfloat/multilingual-e5-small` commit `614241f622f53c4eeff9890bdc4f31cfecc418b3`。
官方 ONNX约470 MB，tokenizer约17 MB，下载合计487,352,505 bytes；大文件SHA-256核验通过。
实际模型/tokenizer内容指纹加入revision，模板 `e5-v1:mean-pool-pad-v1`；384维、cosine、归一化、512token。
CPU线程2、编码batch_size=2；依赖锁定 ONNX Runtime 1.31.0、tokenizers 0.23.3、Qdrant client 1.19.1。
下载、缓存、配置、代次与原始报告均位于项目盘忽略目录，本机位置不公开。

工程验收：66项自动测试通过（63项完整回归，新增3项分别补验）；真实模型`embedding-check`六项通过。
检查长文本完整字符覆盖、完整模板token上限、维度/有限数/归一化、文档与问题的暖缓存0次编码、超长问题拒绝。
另验证超过50个窗口时分页恢复父片段top-k、过滤先于排名、角色/模型缓存隔离、原文版本、更新/删除与删除全部资料。
编码或发布失败保留共同的上一代SQLite/Qdrant快照，错误阶段与报告保留；真实stdio MCP dense与原文版本读取已验收。

API只验收模拟响应：正确鉴权header、结果乱序恢复、错误数量/维度/非有限数拒绝、HTTP错误与正文/密钥脱敏。
未配置实际供应商凭证；不同服务的模型、tokenizer、最大输入与不截断契约仍需配置后验收。
API模式的token数为配置tokenizer的客户端计数，不是实际账单；revision是声明的服务模型版本，不能假定可下载模型那样固定权重。

数据和标签保持smoke-v1，12篇/17父片段；30题中24有证据、6无答案。

逐题收益：q07排序更靠前，q10换说法问题从漏检到命中（rank2）。退化：q06排序下降，q15多证据排序下降；
q25/q26/q27/q30由无候选变为有候选，q28/q29两路原本都有候选。
所有有证据类别Recall为1，但paraphrase的MRR仅0.766667，说明整体Recall不能代替排序质量。
BM25与引入前已有基线质量、返回大小一致。默认仍BM25，dense显式选择，不静默回退。

## 编码与资源

公开语料首次构建17点、1173输入token、缓存miss17；原始编码合计319.208ms。
构建总计12,688.183ms，包括进程模型加载、SQLite快照、缓存读写、持久化、验证与发布。
模型加载4,906.707ms；峰值工作集1,188,982,784 bytes（约1.107GiB），当前工作集约818MiB。
进程内存包括模型、运行时与存储客户端，不是单独权重内存或系统总内存。

无变化重建的独立实测：17次缓存命中、miss0、encode_calls0、encoded_tokens0；仍创建候选快照并写入向量，不是零I/O。
窗口实验完整覆盖超长中文；单窗口最大512token，超长查询明确拒绝。六项验收报告具有代码/fixture/模型指纹与依赖版本。
encode_calls记录编码方法调用数，不是ONNX或HTTP内部批次数。

150次计时查询的客户端编码总token1710、encode_calls150；query_embed p50/p95为6.101/7.560ms，
vector_query p50/p95为13.627/17.842ms，后者包括local存储的每次打开/查询/关闭，不能当作Server纯数据库延迟。
当前计时样本属于单轮小型开发实验；不宣称生产吞吐或性能改善，也未计入MCP传输与外部Agent模型。

## 失败与后续

开发中发现Windows上SQLite连接上下文只提交事务、不关闭连接；修复为显式closing，缓存清理测试验证不再持有文件。
失败候选保留在忽略目录，公开记录不复制私人来源、查询或路径。
服务端部署、并发、自动清理及私人保留测试集仍待完成。模型切换不能共享向量，API key不写入配置序列化或trace。
长父片段摘要仍从片段开头截取，命中窗口的局部证据摘取属于下一阶段上下文实验。

优先建立真实标签后实验hybrid与证据充分性，再针对缓存/持久化开销单独优化，固定输入并交错运行对照。
由于dense无答案候选退化和响应量增加，本次不能宣称幻觉降低或上下文成本降低。
