## 已实现并验证

- Python 3.12.14 开发环境；依赖由 uv.lock 固定，官方 MCP SDK 2.3.0。
- 两个独立演示知识库，12 篇 Markdown、17 个片段。
- 支持本地知识库接入；个人配置与索引位于忽略的 `.state/`，接入细节与私有实验位于 `.local/`。
- SQLite 文档快照、标题路径、YAML 元数据、行号、版本和增删改同步。
- 中文连续双字/英文词项的 overlap 与 BM25 两种检索策略。
- 3 个只读 MCP 工具：知识库列表、搜索、按版本读取原文。
- 已新增 3 个接入工具：get_setup_status、preview_knowledge_base、connect_knowledge_base，以及 Codex install 命令。
- 安装返回当前对话提问与下一步指令；预览不读取正文，确认接入后保存活动配置并立即启用。
- 30 题合成开发集、逐题证据匹配、分类指标、操作阶段 trace、性能样本、返回大小与版本指纹。
- 50 项自动测试全部通过，包含真实 stdio MCP 接入/检索、接入恢复、中文输出、发布隐私及向量存储；无效参数错误是集成测试的预期用例。
- 可选 Qdrant client 1.19.1，由 uv.lock 固定；独立 EmbeddingSpec/Provider、VectorStore 接口及不可覆盖的来源/模型/代次 manifest。
- 固定向量 18 项 local 验收：持久化、预排名过滤、幂等写入/更新/删除、错误批次拒绝；trace 与量化报告默认保留 `.state/`。
- 基线原始报告和 trace 已归档；文档、实验和学习模板已建立。

## 当前基线

以下为 BM25、top_k=5、正文预算 4000 字符；24 道有证据、6 道无答案，每题预热 1 次、测量 5 次。

| 指标 | 实测 |
| --- | ---: |
| 宏平均 Recall@5 | 0.958333 |
| MRR@5 | 0.916667 |
| nDCG@5 | 0.927577 |
| 无答案题无候选比例 | 4/6 |
| 范围外返回数 | 0 |
| 进程内搜索 p50 | 1.459550 ms |
| 进程内搜索 p95 | 1.695505 ms |

这是小型合成开发集的结果，不代表真实知识库准确率、回答质量或部署性能。
计时含本地日志写入、不含 MCP 传输；尚未做多轮交错 A/B、规模或并发实验。

参考：[实验 0001](experiments/0001-lexical-baseline.md)、[公开 BM25 摘要](../benchmarks/public/2026-10-07-bm25/report.json)。

## 已知缺口

1. q10 换说法问题未命中；q28/q29 无答案问题仍返回主题相关候选。
2. 尚无 Embedding、混合检索、重排或证据充分性判断；没有生成式回答。
3. 真实数据质量需要独立查询集；公开合成集分数不能替代真实资料验收。
4. Codex 注册与 MCP 工具调用已有协议验证；具体机器的安装配置与状态只保存本地。
5. 单机、小数据的同步实现；检索每次加载并分词，无性能缓存；文件更新后需手动索引。
6. 当前一来源对应一知识库，Obsidian 链接作为文本，未实现关系图或多模态。
7. 运行日志为本地 JSONL；进程内串行写入。多进程共享日志的可靠归并尚未实现，正式多进程部署应使用独立日志路径或统一日志服务。
8. 真实查询集、保留测试集、准确 token/费用与 Agent 端到端评测尚未建立。
9. 接入引导已在安装命令和服务指令中实现；模型是否按指令提问由安装 Agent 执行，工程测试不等于跨宿主模型行为验证。
10. 接入配置目前只支持一个写入进程；成功接入后的旧索引快照保留在本地，无自动清理。

## 发布边界

此文件只记录项目能力与公开合成实验。具体机器的状态、个人知识库范围、真实问题与引文只记录在 `.local/` 和 `.state/`。
原始 benchmark 报告、数据快照和 trace 默认不提交；`benchmarks/public/` 仅保存校验公开演示语料后导出的聚合摘要。
提交与推送前检查包含已有 Git 历史；首次发布可生成不继承本机旧历史的公开副本。详见 [隐私与发布](privacy.md)。
