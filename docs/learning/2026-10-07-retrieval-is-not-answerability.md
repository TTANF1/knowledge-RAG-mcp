# 检索命中不等于证据足够回答

## 问题

知识库搜到了与问题相关的资料，是否就能让 Agent 正确回答？

## 观察与证据

首轮 30 题演示评测中，q28 询问虚构项目 Orion 的付费用户数量，而资料只有“尚未立项”。
q29 询问 Embedding 模型价格，而资料只讲原理。这两题在两种词法策略下都返回了相关候选。
原始数据见 [EXP-0001](../experiments/0001-lexical-baseline.md)。

## 本实验已验证的结论

- 两个当前检索器都可能对无法回答的问题返回主题相关片段。
- 本次 BM25 改善了一题的排名，没有改善召回，也没有解决上述无答案问题。
- 因此当前服务应把命中称为候选证据，并把充分性判断留给后续明确的环节。

## 待验证的想法

- 语义检索能否改善换说法的问题，同时不过度扩大无答案问题的候选？
- 增加证据充分性判断，能否在拒绝无根据回答和漏答之间取得可量化的改善？
- 将已完成、想法、历史状态等元数据纳入 Agent 的检索流程，会产生多大收益？

## 适用范围

当前结论来自小型公开演示集，尚未测量个人资料或生成式回答。不能据此报告幻觉率下降。
笔记的实测观察有报告支撑；整体保留 draft，待用户核对学习表述后再作为已核对经验回流个人知识库。
