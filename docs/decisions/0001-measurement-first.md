# ADR-0001：采用轻量自建与评测优先

- 日期：2026-10-07
- 状态：accepted
- 来源：用户在本次项目启动对话中明确选择方案一，并要求从最开始考虑 benchmark、关键环节数据记录和可量化优化。

## 决策

使用 Python + SQLite + 官方 MCP SDK，先交付关键词检索基线。所有检索策略通过相同数据集比较。
初期数据库与检索流程保持简单，核心模块不用大型 RAG 框架；必要的 YAML 和协议实现使用成熟库。
Obsidian 作为首个真实来源，公共开发语料使用两个独立的演示知识库。

建立四类项目记录：项目现状、设计决策、实验报告、学习笔记。
后续优化须报告实际收益、代价、退化样例和适用范围。学习笔记通过核对后可回流知识库。

## 代价

早期的词法检索对换说法的问题有局限。索引、评测与协议验证占用初期开发工作，但它们是后续比较的基础。
尚不承诺消除幻觉、自动检索或节省固定比例 token；这些需要 Agent 端到端实测。

## 可重新评估的条件

真实规模导致查询或索引不可接受，或数据源扩展成本显著增加时，再以实验选择新的存储、框架或平台。
